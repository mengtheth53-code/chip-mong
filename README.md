## 🚀 ៥ គំនិតនវានុវត្តន៍ឌីជីថល (5 Product Innovations)

| # | គំនិតនវានុវត្តន៍ (Innovation) | បញ្ហាដែលត្រូវដោះស្រាយ (Problem) | ដំណោះស្រាយ & បច្ចេកវិទ្យា (Solution & Tech) | តម្លៃយុទ្ធសាស្ត្រ (Strategic Value) |
|---|---|---|---|---|
| **4.1** | **Biometric Authentication — One-Touch QuickPay** | ភាពស្មុគស្មាញ និងការចំណាយពេលបញ្ចូល PIN រាល់ពេលទូទាត់ទឹកប្រាក់តូចៗ | ស្កេនម្រាមដៃ/ផ្ទៃមុខរហ័សសម្រាប់ទឹកប្រាក់ < \$10 ដោយមិនបាច់ចុច PIN; Biometric Step-Up Security (> \$10 ទាមទារ PIN/OTP); FIDO2 & Secure Enclave; Face Liveness Detection | បង្កើនល្បឿនប្រតិបត្តិការត្រឹម 0.78s, កាត់បន្ថយ Friction នៅកន្លែងគិតលុយ និងការពារ Shoulder Surfing |
| **4.2** | **AI & Smart Credit System** | "Thin-file Customers" (យុវជន និស្សិត អាជីវករតូច) គ្មានប្រវត្តិឥណទាន CBC មិនអាចខ្ចីលុយបាន | ម៉ាស៊ីន AI វាយតម្លៃ Alternative Credit Scoring តាមរយៈទិន្នន័យលំហូរសាច់ប្រាក់ KHQR និងវិក្កយបត្រ; Digital Nano-Loans (\$50 – \$1,000 គ្មានទ្រព្យបញ្ចាំ); Buy Now Pay Later (BNPL 0%) | ពង្រីកទីផ្សារអតិថិជនថ្មី បង្កើនចំណូលការប្រាក់ និងរុញច្រានការលក់ក្នុងបណ្តាញពាណិជ្ជកម្ម Chip Mong |
| **4.3** | **University Ecosystem Integration** | និស្សិតជួបការលំបាកក្នុងការបង់ថ្លៃសាលា ខ្វះការតភ្ជាប់រវាងធនាគារ និងជីវិតសិក្សា | Digital Student ID សាកល្បងនៅ **សាកលវិទ្យាល័យជាតិគ្រប់គ្រង (NUM)**; បង់ថ្លៃសិក្សា & KHQR អាហារដ្ឋាន; អត្ថប្រយោជន៍ Perks (បញ្ចុះតម្លៃនៅ Supermarket, Legend Cinema, Chip Mong Malls) | ស្រូបទាញនិស្សិតរាប់ម៉ឺននាក់ និងបំប្លែងទៅជាអតិថិជនបើកប្រាក់ខែ (Payroll) & CASA រយៈពេលវែង |
| **4.4** | **Smart Shared Savings** | ការបើកគណនីរួមគ្នានៅសាខាមានភាពស្មុគស្មាញ; ការទុកលុយរួមគ្នាខ្វះតម្លាភាព | គណនីសន្សំរួមឌីជីថលតាមគោលដៅ (Trip Fund \$600, Wedding, Startup); Multi-Party Withdrawal Approval (តម្រូវឱ្យសមាជិកទាំងអស់អនុម័តទើបដកប្រាក់បាន) | ទាក់ទាញយុវជន និងសហគ្រិន បង្កើនទំហំប្រាក់បញ្ញើ និងបង្កើនទំនុកចិត្តដោយ Multi-Sig |
| **4.5** | **Daily Auto-Savings (Micro-Savings)** | អតិថិជនពិបាកសន្សំលុយដុំនៅចុងខែ; ការសន្សំបែបបុរាណទាមទារប្រាក់តម្កល់ខ្ពស់ | កាត់ប្រាក់សន្សំខ្នាតតូចប្រចាំថ្ងៃ (\$1=4,000៛, \$2=8,000៛, \$5=20,000៛); Smart Balance Guard (ផ្អាកស្វ័យប្រវត្តបើលុយសល់ក្រោម \$5); Gamification Streaks & Badges | អតិថិជនសន្សំបាន \$730/ឆ្នាំ; ធនាគារទទួលបាន \$36.5M/ឆ្នាំ ជាប្រភពទុន CASA ថ្លៃដើមទាប |

## 📱 មុខងារសំខាន់ៗនៃកម្មវិធីធនាគារ (Core Banking Features)

* **ផ្ទាំងគ្រប់គ្រងគណនី (Account Dashboard):** បង្ហាញសមតុល្យគណនីចម្បង (KHR/USD), ប៊ូតុងបិទបាំងសមតុល្យ, ប្រវត្តិប្រតិបត្តិការចុងក្រោយ និងស្ថិតិហិរញ្ញវត្ថុ។
* **ប្រព័ន្ធស្កេន KHQR (Bakong Integrated QR):** ស្កេនទូទាត់រហ័សនៅគ្រប់ទីតាំង និងបង្កើត KHQR ផ្ទាល់ខ្លួនសម្រាប់ទទួលប្រាក់។
* **សេវាផ្ទេរប្រាក់ & ទូទាត់វិក្កយបត្រ (Transfers & Bill Payments):** ផ្ទេរប្រាក់ក្នុងធនាគារ, ផ្ទេរឆ្លងធនាគារ (Fast/Bakong), បង់ថ្លៃទឹក ភ្លើង អ៊ីនធឺណិត និងបញ្ចូលលុយទូរស័ព្ទ (Phone Top-up)។
* **ការគ្រប់គ្រងប័ណ្ណ (Card Management):** បង្ហាញកាតនិម្មិត (Virtual Visa/Mastercard), មុខងារបង្កកកាត (Freeze Card) និងកំណត់ទំហំទឹកប្រាក់ចាយវាយ។
* **គណនីមានកាលកំណត់ (Term Deposit):** បង្កើតគណនីបញ្ញើសន្សំមានកាលកំណត់តាមទូរស័ព្ទ ជាមួយនឹងអត្រាការប្រាក់ខ្ពស់ប្រកួតប្រជែង។
* **ទីតាំងសាខា & ទូ ATM (Branch Locator):** ស្វែងរកទីតាំងសាខាធនាគារ និងទូ ATM Chip Mong ដែលនៅជិតបំផុត។
* **Innovation Hub Presentation:** ទំព័របទបង្ហាញគំនិតច្នៃប្រឌិតទាំង ៥ ជាមួយនឹងមុខងារប្តូរភាសាពីរ (**🇰🇭 ខ្មែរ / 🇬🇧 EN**)។

## 💻 របៀបតម្លើង និងដំណើរការកម្មវិធី (Getting Started)

### លក្ខខណ្ឌតម្រូវ (Prerequisites)
* Flutter SDK: `^3.x.x`
* Dart SDK: `^3.x.x`
* Android Studio / VS Code
* Android SDK 34+ / iOS 15+

### ជំហានតម្លើង (Installation Steps)
1. **Clone repository នេះមកកាន់កុំព្យូទ័ររបស់អ្នក៖**
   ```bash
   git clone https://github.com/mengtheth53-code/chip-mong.git
   cd chip-mong
   ```

2. **ទាញយក Packages/Dependencies ទាំងអស់៖**
   ```bash
   flutter pub get
   ```

3. **ត្រួតពិនិត្យភាពត្រឹមត្រូវនៃកូដ (Code Analysis):**
   ```bash
   flutter analyze
   ```

4. **ដំណើរការកម្មវិធីលើ Device ឬ Emulator (ឧទាហរណ៍ Android Pixel 6):**
   ```bash
   flutter run
   ```
